# Veera AI — English at Work · PoC

Static site, no build step. Open `index.html`.

- `index.html` — overview with links
- `funnel/` — quiz → voice trial → plan → paywall
- `app/` — first app session
- `veera-data.json` — all personalised content (a copy is built into both pages)

Demo personas: add `#persona-a` or `#persona-b` to the funnel or app URL, e.g. `funnel/#persona-a-plan`.
